# Agent Instructions — Verittà Think Tank

## Repository role

This repository is the public editorial and research surface of the Verittà Think Tank. It is not the sovereign operational HQ of the wider Verittà ecosystem.

Do not infer access to private canon, private agent hierarchy, credentials, customers, live deployments or unredacted Forge records.

## Start here

1. Human documentation index: `docs/index.md`
2. Public source-of-truth boundary: `docs/foundations/source-of-truth-map.md`
3. Public research index: `docs/research/README.md`
4. V-COF reinstantiation agent map: `docs/research/vcof-reinstantiation/AGENTIC_MAP.yaml`
5. Project adversarial review: `docs/research/vcof-reinstantiation/METACOGNITIVE_ADVERSARIAL_REVIEW_2026-06-21.md`

## Precedence

- The public source-of-truth map governs repository-wide interpretation.
- Project agentic maps govern local reading order and artifact status.
- Ratification is bounded to the identified proposal version and scope.
- A seal records completion and limitations; it does not create new authority.
- Proposals, advisory notes and confidence scores are not authorization.
- Presence on `main` means public visibility and versioning, not empirical validation.

## Research integrity

When working in `docs/research/`:

- distinguish definitions, designs, normative claims and empirical claims;
- do not state that V-COF is empirically validated until supported results are merged;
- preserve negative results, exclusions, deviations and critical failures;
- maintain provenance for inherited claims and citations;
- do not claim personal memory or numerical identity across agent instances;
- treat named agent lineages as computational research artifacts, not human authors;
- minimize personal data and protected internal material;
- update the project README and agentic map when artifact status changes.

## Change discipline

Before proposing or merging changes:

- inspect existing placement conventions;
- avoid loose files in `docs/` root;
- run or await `docs-structure-guardrail`;
- run or await relevant project CI;
- do not bypass failing checks by weakening a guardrail without documenting the taxonomy decision;
- keep paid API execution, spending, external submission and protected disclosure behind explicit human ratification.

## V-COF reinstantiation status

The current public program is pre-empirical. It includes a working manuscript, ontology, preregistration, synthetic pilot episodes and local harness. No paid pilot result exists in the canonical public record.
