## Purpose

This directory contains the public, versioned design package for the V-COF Core
2.2 release candidate. It translates a bounded architectural update into public
specifications, schemas, evaluation rules and a migration challenge plan.

V-COF means **Verittà Cognitive-Operational Framework**. The expression
"contract-governed operations" names an execution discipline inside the
framework; it is not an alternative expansion of the acronym.

## Public authority boundary

This package is canonical only for the public proposal record maintained in the
Verittà Think Tank. It is not the sovereign operational canon of the wider
Verittà ecosystem and does not amend private constitutions, activate live
agents, change credentials, deploy software or authorize production effects.

The repository-wide [public source-of-truth map](../../foundations/source-of-truth-map.md)
prevails over this package. If this public candidate diverges from sovereign
internal canon, the public candidate must be corrected.

## What was ratified

The human Judge ratified preparation of this package on a dedicated Git branch
and presentation through a pull request, with the following hard limits:

- no merge;
- no production mutation;
- no disclosure of protected internal material;
- no empirical-validation claim;
- no activation of a new framework version in live operations.

The bounded record is preserved in
[RATIFICATION_RECORD_2026-07-10.md](./RATIFICATION_RECORD_2026-07-10.md).

## Current decision gate

The present authority envelope ends when the draft pull request has been
created and its checks and challenges have been reported to the human Judge.
Merge, internal adoption, operational migration, paid evaluation, public
release on `main` and a future V-COF 3.0 designation each require a new,
explicit and version-bound decision.
